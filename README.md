# 📊 Data Analytics Portfolio

Data analytics projects using Excel, SQL, and Python — covering exploratory
analysis, revenue and behavioural studies, and tooling built to make the
analysis process faster.

Each project folder has its own README with the full write-up: background,
approach, findings, and how to reproduce it.

## 📂 Projects
| Project | Tools | Description |
|---|---|---|
| [Retail Sales Dashboard (Excel)](projects/retail-sales-dashboard) | Microsoft Excel | Analyzes retail sales performance across regions, product categories, and time periods. |
| [International Students & Mental Health — SQL Analysis](projects/student-mental-health-sql) | PostgreSQL | Analyzes survey data to test whether length of stay abroad relates to depression, social connectedness, and acculturative stress. |
| [Motorcycle Parts Wholesale — SQL Revenue Analysis](projects/motorcycle-parts-wholesale-sql-analysis) | PostgreSQL | Analyzes wholesale revenue by product line, warehouse, and month for a motorcycle parts retailer, including bulk-pricing, fee, and revenue-concentration findings. |
| [Dataset Review Agent — Automated Data Quality Assessment](projects/dataset-review-agent) | Python, pandas | Profiles any CSV or Excel file, diagnoses the data quality problems that distort analysis, and generates a report ranking what to fix first. |
